# Introduction
图像基本单位是像素。
在数字图像中，颜色实际上是光的亮度和色彩值的组合。
这2个值，底层都是0-255. 所以可以用来映射。
## 白色和黑色
白和黑正常情况下是颜色，但在遮罩、渐变等应用中常常不是单纯的颜色，而是 透明度的代表。

例如
- **白色（White）**    
    - RGB 表示：`R=255, G=255, B=255`（最大值）        
    - 亮度最大，视觉上最亮。        
    - 在叠加时，如果用作遮罩（mask），通常表示“完全显示”或“完全可见”。
        
- **黑色（Black）**    
    - RGB 表示：`R=0, G=0, B=0`（最小值）        
    - 亮度最小，视觉上最暗。        
    - 在叠加遮罩中通常表示“完全隐藏”或“完全透明”。
## 透明、不透明、半透明
- **透明 (Transparent)** 
	- 看不到这个像素，显示下面的内容    
    - RGBA 中 A=0        
- **不透明 (Opaque)** 
	- 完全显示前景像素，覆盖背景。   
    - RGBA 中 A=255        
- **半透明 (Semi-transparent)** 
	- 前景和背景混合显示    
    - RGBA 中 A=1~254
# 像素（Pixels）
## basics
- **像素** = **图像的最小单位**，类似“图像的砖块”，是屏幕上的一个点
- 每个像素包含颜色信息（R/G/B）和可能的透明度（A）    
- 一张图像就是由大量像素排列组成的网格
- 像素数量决定图像的清晰度和分辨率
## 像素的组成
像素里存什么信息，取决于 颜色模型：
### RGB 彩色像素
每个像素有 3 个通道：红 R、绿 G、蓝 B
每个通道取值 0~255（8 位）
通过三色混合形成各种颜色

| R   | G   | B   | 颜色  |
| --- | --- | --- | --- |
| 255 | 0   | 0   | 红色  |
| 0   | 255 | 0   | 绿色  |
| 0   | 0   | 255 | 蓝色  |
| 255 | 255 | 255 | 白色  |
| 0   | 0   | 0   | 黑色  |
| 255 | 255 | 0   | 黄色  |
### RGBA 彩色像素（带透明度）
多了一个 Alpha 通道（A）控制这个像素的 透明度(可见度)
0 = 完全透明
255 = 完全不透明

#### Alpha
alpha值的用途：图像/视频叠加（前景 + 背景）、图像/视频特效（渐隐、淡入淡出）

在处理图像或视频叠加时，Alpha 通道告诉软件 哪些像素属于前景（可见），哪些属于背景（透明或半透明）：
> 这里，前景（Foreground）指我们想保留的部分；背景（Background）指我们想去掉的部分
> 换句话说，Alpha 通道定义了“前景有多少可见，背景有多少透出来”。
> **前景（Alpha 高值）** → 要显示的主体
> **背景（Alpha 低值）** → 被抠掉或透出的部分
> Alpha 通道本质上就是一张“前景/背景的灰度蒙版图”

**叠加公式**：
```
最终颜色=前景颜色×α+背景颜色×(1−α)
```

|Alpha 值|表示|角色|
|---|---|---|
|255（不透明）|颜色完全显示|**前景**|
|0（完全透明）|颜色不可见|**背景**|
|1~254 / 0~1|半透明|**前景和背景混合**|
例子

| R   | G   | B   | A   | 效果       |
| --- | --- | --- | --- | -------- |
| 255 | 0   | 0   | 255 | 完全红色显示   |
| 255 | 0   | 0   | 128 | 半透明红色    |
| 255 | 0   | 0   | 0   | 完全透明，看背景 |
例子，你有一张人物抠图：
- 人物部分 Alpha = 255 → **前景**    
- 抠掉的背景部分 Alpha = 0 → **背景**    
- 边缘羽化部分 Alpha = 100 → 半透明 → 前景和背景融合
```makefile
背景（完全透明）: ·
前景（完全不透明）: █
半透明: ░

图例：
░░░░░░░░░░░░░░░░░░░░░░
░░░░██████░░░░░░░░░░░
░░█████████░░░░░░░░░░
░███████████░░░░░░░░░
░░█████████░░░░░░░░░░
░░░░██████░░░░░░░░░░░
░░░░░░░░░░░░░░░░░░░░░░
```
前景（Alpha = 255 / 不透明），会完全显示出来
背景（Alpha = 0 / 透明），这个区域会被抠掉，显示出下层其他图像
半透明区域（Alpha 中间值），边缘羽化或过渡，让前景和背景融合
#### 羽化（Feathering）
**羽化 = 边缘柔化 / 模糊化** = 前景边缘从完全不透明到完全透明的渐变过渡
- 当你从图像中抠出前景（主体）时，前景和背景的边缘可能很生硬，出现“锯齿”或“硬边”。    
- **羽化就是让前景边缘逐渐过渡到背景，使边缘看起来柔和自然**。    
- 技术上，它是 **Alpha 通道的渐变处理**。
- 羽化是前景边缘的“模糊过渡区”，让前景和背景自然融合。
## 像素与图像大小
图像宽 × 高 = 像素总数
例子：540x480
宽 540 像素，高 480 像素
总像素数 = 540 × 480 = 259,200 个像素
像素越多 → 图像越清晰（分辨率高）
像素越少 → 图像模糊、马赛克感明显
# 分辨率
分辨率 = 图像的像素数量
通常表示为 宽 × 高（Width × Height），单位是像素（Pixel）
例如：
```
1920×1080 → 宽 1920 像素，高 1080 像素
540×480 → 宽 540 像素，高 480 像素
```
分辨率越高 → 像素越多 → 图像越清晰
### 分辨率 vs 图像尺寸
分辨率决定像素数量
**图像尺寸（physical size）**决定显示或打印大小
例如：
两张图都是 1920×1080 像素
显示在手机屏幕上 → 清晰
打印到 2 米高的大海报 → 可能模糊
打印时需要考虑 DPI（dots per inch）
### DPI = 每英寸的点数(墨点数量)
它表示 打印或显示图像时，每英寸长度上有多少个独立的点。
DPI 通常用于 打印输出，而不是屏幕显示。屏幕显示主要看 像素分辨率（像素数量），屏幕显示的 PPI（Pixels Per Inch，像素每英寸），。

例子：
如果一张图片是 300 DPI，说明每英寸有 300 个点。
如果一张图片是 72 DPI，说明每英寸有 72 个点。
### DPI vs PPI

| 缩写      | 全称                      | 主要应用        | 含义                    | 区别            |
| ------- | ----------------------- | ----------- | --------------------- | ------------- |
| **DPI** | Dots Per Inch（每英寸点数）    | **打印**      | 表示打印机每英寸可以打印多少个墨点（点阵） | 打印输出精度        |
| **PPI** | Pixels Per Inch（每英寸像素数） | **屏幕/数字图像** | 表示屏幕或图像每英寸包含多少像素点     | 屏幕显示精度或图像数字精度 |
- PPI 决定了 **数字图像的密度**（像素分布），DPI 决定了 **打印出来的密度**（墨点分布）。    
- 打印时，通常 PPI 和 DPI 相匹配，这样图片打印才清晰。
公式关系：
``` math
打印尺寸（英寸）= 像素数 / (DPI 或 PPI​)
```
示例：
- 一张图像 3000×2400 px，如果打印机设置 300 DPI（每英寸 300 点）：    
    - 打印宽度 = 3000 ÷ 300 = 10 英寸        
    - 打印高度 = 2400 ÷ 300 = 8 英寸
        
- 如果打印机 DPI 设置成 150：    
    - 打印宽度 = 3000 ÷ 150 = 20 英寸        
    - 打印高度 = 2400 ÷ 150 = 16 英寸        

> 注意：像素数没变，打印尺寸变大了，但清晰度下降。

屏幕：你看到的是 像素点（PPI）
打印：打印机用墨水点形成图像（DPI）
高 PPI + 高 DPI → 打印清晰

常见数值
- 屏幕 PPI：普通显示器 ≈ 72~110，手机高分屏可达 300~500    
- 打印 DPI：普通喷墨 ≈ 150~300，专业打印 ≈ 600~1200
数值越大越好，但够用就行
# 颜色模型
颜色模型 = 定义像素如何存储颜色的规则
前面说过，图像其实就是由 **像素 (Pixel)** 组成的网格，每个像素包括颜色信息。
每个像素不是单纯的黑白，它通过 不同通道的数据组合 来表示颜色

常见颜色模型包括：

| 模型                 | 含义             | 通道                            | 用途                     |
| ------------------ | -------------- | ----------------------------- | ---------------------- |
| **RGB**            | 红绿蓝            | R、G、B                         | 显示彩色图像，电视、显示器常用        |
| **RGBA**           | 红绿蓝+透明         | R、G、B、A                       | 彩色图像 + 透明度控制，用于合成图像/视频 |
| **灰度 (Grayscale)** | 只有黑白亮度<br>没有颜色 | 1个通道<br>像素值表示亮度:<br>0=黑，255=白 | 黑白图片、Alpha mask<br>    |
| CMYK               | 青品红、黄、黑        | C, M, Y, K                    | 印刷                     |
## 灰度图（Grayscale Image）
就是只保留 **亮度信息** 的图像，没有颜色信息。每个像素只存亮度值。
> 所谓“亮暗”，就是这个像素看起来有多亮或多暗。
> 就是完全显示这个像素，暗就是像素变灰或变黑
值的范围通常 0~255
0 → 黑色=亮度最小 =前景完全隐藏
255 → 白色=亮度最大=前景完全显示
中间值 → 灰色=中间亮度 = 前景半透明
**ASCII 示例**（亮度由深到浅）：
```
█▓▒░
```
常用作 遮罩（mask） 或黑白图像
## Alpha 通道 vs 灰度图
|属性|灰度图 (Grayscale)|Alpha 通道 (Alpha)|
|---|---|---|
|**主要作用**|表示亮度/强度|表示透明度/可见性|
|**数值意义**|0 → 黑（最暗），255 → 白（最亮）|0 → 完全透明，255 → 完全不透明|
|**颜色信息**|没有，只是亮度|没有，只是透明度|
|**用途**|图像处理、滤镜、分析|抠图、叠加、羽化、遮罩|
### 二者的相似点
都是单通道（单值）图像
每个像素只有一个值, 值越大越“显眼”，越小越“隐”
这个值都可以用 0~255 表示
Alpha：0 = 透明（像素看不见），255 = 不透明（像素完全可见）
灰度：0 = 黑色（像素看不见），255 = 白色（像素完全可见）
中间灰度 → 半透明 / 半亮
### 区别
**本质上，Alpha 通道是 一种特殊的灰度图**，但它的数值不表示亮度，而是透明度。
Alpha 通道 → **窗帘开关**（能看见或看不见）
灰度图表示亮暗，与透明无关。
灰度图亮暗 → **灯泡的亮度**

**灰度图可以用作蒙版**，实现类似 Alpha 通道的效果。原始灰度图表示亮暗；用作蒙版后，其灰度值语义变成了“透明度”
Alpha 通道 = 灰度图 + “透明度语义”
灰度图本身不是 Alpha，但可以被当作蒙版来模拟 Alpha 效果。
### 应用举例
- 图像叠加：把一张图的灰度图作为蒙版，控制前景和背景的透明度    
- 羽化边缘：用渐变灰度图制作前景边缘透明过渡效果    
- 特效合成：通过灰度蒙版控制光影、渐变、滤镜效果
## 蒙版（Mask）
蒙版就是一张 灰度图。是一张用来控制图像或图层哪些部分可见、哪些部分隐藏的灰度图
黑色（0） → 隐藏
白色（255） → 显示
灰色 → 半透明 / 部分显示

应用
1. **抠图**：把前景从背景中分离出来    
2. **图层编辑**：局部调整亮度、颜色或特效    
3. **羽化/渐变过渡**：通过灰度渐变控制透明度

直观示意
```makefile
背景: ·····
蒙版:
···      ← 黑色部分隐藏
░░░      ← 灰色部分半透明
███      ← 白色部分显示
```
这就是蒙版的工作原理：用灰度图控制透明度，实现前景叠加在背景上。

```
灰度图叠加到原图上，就实现了部分透明。
原因灰度图和alpha通道都是单值，都是0-255。
可以直接把灰度图的值转成alpha通道：灰度图亮度值 → 直接映射成 Alpha值（亮 → 不透明，暗 → 透明） → 控制前景透明度。
```

### 遮罩（Mask / Matte）
在视频或动画中应用蒙版时，它就叫做遮罩（Mask / Matte）。
遮罩是蒙版的一个应用形式，通常指在 **视频**或特效制作中用来控制显示区域的灰度图或Alpha图
本质上仍然是灰度图，但语境更多用于：

- 视频合成
- 动画特效
- 控制前景/背景透明度

遮罩通常是临时用途，用来做**特效或叠加**    
蒙版则概念更广，也可以用于静态图片处理
静态图像里叫蒙版，视频或动画里用它做透明控制就叫遮罩。

# 通道（Channel）
通道 = 存放单一属性的一层“平面数据”
每个像素的某个属性（红色、绿色、蓝色、亮度、透明度）都在对应的通道里记录

一个 RGB 彩色图像有 3 个通道：

| 通道       | 描述   | 值的范围  |
| -------- | ---- | ----- |
| R（Red）   | 红色分量 | 0~255 |
| G（Green） | 绿色分量 | 0~255 |
| B（Blue）  | 蓝色分量 | 0~255 |
- 每个通道其实是一个 **灰度图**：数值越大，亮度越高  
- 三个通道叠加 → 得到彩色

RGBA模型中，Alpha 通道也是一个 **灰度图**

常见格式及特点

| 格式   | 通道            | 是否支持透明 | 压缩方式    | 用途                         |
| ---- | ------------- | ------ | ------- | -------------------------- |
| PNG  | RGB / RGBA    | ✅ 支持   | 无损      | 图标、透明图片、合成                 |
| JPG  | RGB           | ❌ 不支持  | 有损      | 照片、网页图片                    |
| GIF  | RGB + 1 bit透明 | ✅ 支持   | 有损 / 动画 | 动画、简单透明。<br>只有透明/不透明；没有半透明 |
| BMP  | RGB           | ❌ 不支持  | 无损      | Windows 原始图像               |
| TIFF | RGB / RGBA    | ✅ 可选   | 有损/无损   | 专业印刷、摄影                    |
| WEBP | RGB / RGBA    | ✅ 支持   | 有损/无损   | 网页、移动端                     |
> 注意：**只有支持 Alpha 的格式（如 PNG、TIFF、WEBP）才能保存透明信息**
# 渐变（Gradient）
渐变 = 颜色或亮度的平滑过渡
类型：
线性渐变（Linear Gradient）
- 沿直线变化，例如从上到下、左到右    
- 白→黑渐变常用作 Alpha 遮罩
径向渐变（Radial Gradient）
- 从中心向外扩散    
- 常用于光晕或聚光效果
自定义曲线渐变（Custom Gradient）
- 不规则变化，可用曲线控制亮度/颜色过渡
例如（ASCII 白黑渐变，垂直方向）：
```
█████  <- 白 (Alpha=255)
▓▓▓▓▓  <- 浅灰 (Alpha≈192)
▒▒▒▒▒  <- 中灰 (Alpha≈128)
░░░░░  <- 深灰 (Alpha≈64)
□□□□□  <- 黑 (Alpha=0)
```
亮度由白到黑变化 → Alpha 通道控制前景透明度

用途
- **Alpha 遮罩**：淡入淡出、渐显渐隐    
- **背景/装饰色**：天空渐变、光影效果    
- **特效**：烟雾、光照、阴影
# 图像叠加 / 合成（Composition）
叠加 = 前景 + 背景 + Alpha 通道
每个像素的最终显示由前景透明度决定
**公式（每个像素）**：
```
最终颜色=前景颜色×α+背景颜色×(1−α)
```
alpha取值有2个范围: 0-255或0-1
- **Alpha = 255 / 1 → 完全显示前景**    
- **Alpha = 128 / 0.5 → 前景/背景各占一半**    
- **Alpha = 0 / 0 → 完全显示背景**

例子，假设红色前景 F，蓝色背景 B：
```r
Alpha=255 → F F F F F  (完全前景)
Alpha=128 → F F B B F  (半透明)
Alpha=0   → B B B B B  (完全背景)
```
- **多图叠加**可以重复应用公式，最终效果由多层 Alpha 决定    
- 常用在 **视频特效、图像合成、游戏 UI**
# 色彩深度（Bit Depth）
色彩深度 = 每个通道用多少位存储亮度/颜色信息
决定颜色/亮度的精细程度
常用值

| Bit Depth    | 数值范围    | 描述                            |
| ------------ | ------- | ----------------------------- |
| 8 bit        | 0~255   | 每通道256级亮度或颜色 → 24bit RGB 彩色图像 |
| 16 bit       | 0~65535 | 每通道65536级亮度 → 高精度图像，过渡平滑      |
| 32 bit float | 0~1浮点   | 高精度图像处理、HDR                   |
举例
- 8 bit：红色通道值 128 → 中红    
- 16 bit：红色通道值 32768 → 精细中红  

与渐变的关系
- Bit depth 越高 → 渐变越平滑    
- 低 bit depth → 渐变可能出现 **色带（banding）**

与叠加的关系
- 前景半透明叠加背景 → Bit depth 决定计算精度    
- 高 bit depth → 叠加更平滑，不会产生颜色阶梯

# FAQ
### 白→黑渐变图
你在画图软件（Photoshop、GIMP、Paint、Affinity 等）手工画一张白色到黑色的渐变图。
就是一张普通灰度图，能直接作为Alpha mask（遮罩），用来叠加做渐隐效果

用命令行生成的白黑渐变图
```
magick -size 540x480 gradient:white-black bottom_gradient.png
```
功能：自动生成从白到黑的渐变图
尺寸、方向、线性程度可指定
本质上和你手工画的图 效果完全一致
