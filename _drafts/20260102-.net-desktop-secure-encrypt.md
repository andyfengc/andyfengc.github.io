# Introduction
对于基于 .NET 的桌面程序（如 WPF 和 WinForms），由于 C# 代码会被编译成 **中间语言 (MSIL)**，很容易被反编译成接近源码的状态（如使用 dnSpy 或 ILSpy）。因此，防止盗版是一场“攻防战”，没有绝对的防破解，只有不断提高破解成本。
.NET 程序防盗版措施汇总

|**措施类别**|**具体手段**|**防御原理**|**优缺点**|
|---|---|---|---|
|**代码保护 (核心)**|**混淆 (Obfuscation)**|更改类名、方法名为无意义字符，混淆控制流。|**优点**：简单、成本低。<br><br>  <br><br>**缺点**：不改变逻辑，熟练工仍可破解。|
||**加壳 (Packing/Shielding)**|将 DLL/EXE 压缩加密，在内存中动态解密运行。|**优点**：防止直接反编译文件。<br><br>  <br><br>**缺点**：可能被杀毒软件误报。|
||**代码虚拟化 (Virtualization)**|将 IL 指令转换为私有自定义指令集，在虚拟机中运行。|**优点**：**最强防御**，反编译后几乎无法阅读。<br><br>  <br><br>**缺点**：会牺牲部分性能。|
|**授权验证**|**本地授权码 (License Key)**|根据 CPU/主板/硬盘序列号生成机器码，绑定激活。|**优点**：支持离线运行。<br><br>  <br><br>**缺点**：注册机容易被逆向。|
||**网络激活 (Online Activation)**|启动时通过服务器校验授权状态，心跳包检测。|**优点**：控制力强，可随时远程撤销授权。<br><br>  <br><br>**缺点**：必须联网，依赖服务器稳定性。|
|**硬件绑定**|**加密狗 (Hardware Dongle)**|使用 USB 硬件令牌，核心算法或密钥存储在硬件内。|**优点**：**极难破解**，无法通过复制软件运行。<br><br>  <br><br>**缺点**：硬件成本高，快递物流不便。|
|**架构演进**|**云端逻辑 (Cloud Logic)**|将核心计算逻辑搬到 Web API，本地程序仅作为 UI。|**优点**：**降维打击**，本地没有核心源码可破。<br><br>  <br><br>**缺点**：对网络延迟敏感。|
|**自我防护**|**反调试/反改写**|检测运行环境是否处于 Debug 状态，校验 DLL 签名。|**优点**：增加动态调试和汉化改写的难度。<br><br>  <br><br>**缺点**：容易被“跳过”检测点。|
**代码混淆 (如 Dotfuscator, Obfuscar)** + **网络授权 (JWT/OAuth2)** + **机器码绑定**。
你的核心逻辑（控制流）在云端受保护，而沉重的计算任务和海量数据（数据流）留在用户本地，利用用户的 CPU/GPU 性能。
### 架构流程图

在这种模式下，程序的工作流如下：

1. **本地预处理：** WPF 程序调用本地 FFmpeg 获取媒体信息（如帧率、时长）。
    
2. **参数上报：** 客户端将“元数据”（不是大文件，只是参数）发给云端。
    
3. **云端决策：** 远程算法计算出复杂的 FFmpeg 命令行参数或滤镜脚本（FF-Script）。
    
4. **本地执行：** 客户端接收云端下发的“指令指令”，在本地拉起 FFmpeg 进程完成渲染。

#### 如何防止用户破解“云端指令”？

如果你的算法只是返回一行简单的 `ffmpeg -i input.mp4 -vf "..."`，用户打开任务管理器就能看到你的核心参数。

- **对抗方案：** 不要直接返回命令行字符串。返回一组**加密的 JSON 指令**，在 C# 内部解析并使用 `ProcessStartInfo` 启动，不要让参数显示在日志或控制台中。
#### 远程算法接口示例 (ASP.NET Core)

服务端只负责“算计”而不负责“处理”：

C#

```
[HttpPost("calculate-process-params")]
public IActionResult GetParams([FromBody] MediaInfo info)
{
    // 1. 验证用户权限/会员等级
    // 2. 根据 info.Duration, info.Bitrate 运行核心算法
    var script = MySecretAlgorithm.GenerateComplexFilter(info);
    
    // 3. 返回加密后的参数
    return Ok(new { EncryptedTask = AES.Encrypt(script) });
}
```
