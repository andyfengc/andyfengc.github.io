# Introduction
Advanced SubStation Alpha (扩展型字幕格式)比传统的 `.srt` 字幕强大，支持丰富的样式、特效和定位。
## 优势
- 支持字体、颜色、阴影、描边    
- 可精确定位字幕在画面上的位置    
- 支持逐字卡拉OK 特效（K 歌常用）    
- 强大的特效（移动、旋转、缩放、透明度变化）    
- 兼容 FFmpeg，可以直接烧录进视频
# Structure
一个 `.ass` 文件通常分成几个部分，用类似 INI 配置文件的格式组织：
## Script Info
描述整个字幕文件的元信息。  
示例：
```ini
[Script Info]
; 这是注释
Title: 我的字幕
Original Script: Andy
ScriptType: v4.00+
PlayResX: 1920
PlayResY: 1080
Timer: 100.0000
WrapStyle: 0
```
- `PlayResX` 和 `PlayResY`：字幕显示的分辨率，常见 1280x720 或 1920x1080。    
- `WrapStyle`：换行方式（0–3）。    
- `Timer`：全局时间缩放（一般保持 100.0000）。
### WrapStyle
定义字幕文本 自动折行（Word Wrapping）行为。这个参数决定了当一行文本的宽度超过字幕框的可用宽度时，文本将如何被分割成多行。

| **值** | **名称**                                 | **行为描述**                                                                                                       |
| ----- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **0** | **智能折行 (Smart Wrapping)                | **推荐值。** 文本很多，行宽不足时自动换行，避免拆词（英文单词不被拆开）<br>优先在**单词边界**进行折行（空格处自动换行）。如果一行只有一个很长的词，它会强制在词内部折行以适应屏幕。               |
| **1** | **行尾折行，无单词内折行** (End-of-Line Wrapping) | 文本只会在到达行尾时折行，且**只在单词之间的空格处**折行。如果一个长单词的长度超过了字幕框的宽度，它将**溢出**屏幕，而不会在单词内部被截断。<br>碰到\N折行。<br>适用卡拉ok字幕。和需要精确控制位置的字幕 |
| **2** | **无折行** (No Wrapping)                  | 完全禁用自动折行。文本会显示在一行上，即使溢出字幕框。在此模式下，只有 ASS 文件中明确使用的手动换行符（`\N`）才会生效。                                               |
| **3** | 等宽智能折行（smart but equalized wrapping）   | 类似 model 0.<br>但是会让每一行的长度尽量接近，比如一行的单词少，会自动拉宽，作用于多行字幕时保持视觉对齐。<br>适合诗句，对话格式字幕。                                   |
## Styles
定义字幕的样式（字体、大小、颜色、边框等）。  
示例：
```ini
[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
Style: Default,Microsoft YaHei,48,&H00FFFFFF,&H0000FFFF,&H00000000,&H64000000,-1,0,0,0,100,100,0,0,1,2,2,2,20,20,20,1
```
### Format
Format 规定了样式字段的顺序（必须固定）。
### Style
`Style:` 就是一条样式定义，必须严格按照 Format 的字段顺序填写。
**Styles 区** = 定义“字幕外观模板”（所有参数必填，参数固定顺序）

| 字段                  | 必填  | 类型/值范围             | 说明                                             |
| ------------------- | --- | ------------------ | ---------------------------------------------- |
| **Name**            | 必填  | 任意字符串（不能含逗号）       | 样式名，后续 Events 会引用                              |
| **Fontname**        | 必填  | 系统存在的字体名           | 例：`Arial`、`Microsoft YaHei`                    |
| **Fontsize**        | 必填  | 正整数                | 字体大小（像素单位）                                     |
| **PrimaryColour**   | 必填  | BGR 顺序的 &HAABBGGRR | 主字体颜色，带透明度（AA=透明度）                             |
| **SecondaryColour** | 必填  | 同上                 | 二级颜色，用于卡拉OK 高亮                                 |
| **OutlineColour**   | 必填  | 同上                 | 字体描边颜色                                         |
| **BackColour**      | 必填  | 同上                 | 背景色或阴影色                                        |
| **Bold**            | 必填  | -1=加粗, 0=正常        | 是否加粗                                           |
| **Italic**          | 必填  | -1=斜体, 0=正常        | 是否斜体                                           |
| **Underline**       | 必填  | -1=下划线, 0=无        | 是否有下划线                                         |
| **StrikeOut**       | 必填  | -1=删除线, 0=无        | 是否有删除线                                         |
| **ScaleX**          | 必填  | 百分比（默认100）         | 横向缩放，200=放大一倍                                  |
| **ScaleY**          | 必填  | 百分比（默认100）         | 纵向缩放                                           |
| **Spacing**         | 必填  | 整数或小数              | 字符间距，正=加宽，负=压缩                                 |
| **Angle**           | 必填  | 浮点数                | 字体旋转角度（度数，逆时针）                                 |
| **BorderStyle**     | 必填  | 1=描边, 3=盒子背景       | 边框样式                                           |
| **Outline**         | 必填  | 非负数                | 描边粗细（单位像素）                                     |
| **Shadow**          | 必填  | 非负数                | 阴影距离（像素）                                       |
| **Alignment**       | 必填  | 1–9                | 对齐方式, 字幕位置（类似小键盘 1–9 对应屏幕方位 1左下，5居中，9右上）       |
| **MarginL**         | 必填  | 非负整数               | 左边距（覆盖对齐位置）                                    |
| **MarginR**         | 必填  | 非负整数               | 右边距                                            |
| **MarginV**         | 必填  | 非负整数               | 垂直边距（顶部或底部）                                    |
| **Encoding**        | 必填  | 0–指定编码             | 常用 1=ANSI, 128=Shift-JIS, 134=GB2312, 136=BIG5 |
## Events
真正的字幕内容。  
示例：
```ini
[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
Dialogue: 0,0:00:00.28,0:00:10.49,Default,,0,0,0,,我和我的祖国一刻也不能分割
Dialogue: 0,0:00:10.50,0:00:15.00,Default,,0,0,0,,永远和你心连心
```
### `Format` 
第一行 `Format:`规定了字段顺序。
### Dialogue
每行 `Dialogue:` 就是一条字幕事件。
- **必填项**：Name, Fontname, Fontsize, 颜色, Bold, Italic, BorderStyle, Outline, Shadow, Alignment, Margins, Encoding（在 Styles）；Layer, Start, End, Style, Text（在 Events）    
- **可选项**：Name（角色）、Effect（特效）、Margins（覆盖样式）

| 字段          | 必填  | 类型/值范围       | 说明                               |
| ----------- | --- | ------------ | -------------------------------- |
| **Layer**   | 必填  | 整数（0–∞）      | 图层，数值越大越在上方                      |
| **Start**   | 必填  | `h:mm:ss.cs` | 开始时间（cs=百分之一秒）                   |
| **End**     | 必填  | `h:mm:ss.cs` | 结束时间                             |
| **Style**   | 必填  | 样式名          | 对应 [Styles] 定义的样式                |
| **Name**    | 选填  | 字符串          | 说话人姓名或标签（常为空）                    |
| **MarginL** | 选填  | 非负整数         | 单独调整该行左边距，0=使用样式默认               |
| **MarginR** | 选填  | 非负整数         | 单独调整该行右边距                        |
| **MarginV** | 选填  | 非负整数         | 单独调整该行垂直边距                       |
| **Effect**  | 选填  | 特效标签         | 如 `Scroll up;50;500`、`Karaoke` 等 |
| **Text**    | 必填  | 字符串（可含标签）    | 字幕文本，支持 `{\tag}` 覆盖样式，可以包含特殊标签   |
## 标签（Override Tags）

在 `Text` 里可以加入 `{}` 包围的标签，实现局部特效。  
例如：
```scss
{\b1}粗体{\b0} 正常
{\i1}斜体{\i0} 正常
{\c&H0000FF&}蓝色字体
{\fs60}60号大字
{\pos(200,400)}固定在屏幕坐标(200,400)
{\move(100,100,500,500,0,2000)}2秒内从(100,100)移动到(500,500)
{\k87}卡拉OK逐字高亮
```

## ASS的颜色
ASS 可以用到 4 种颜色参数：
1. **PrimaryColour**（默认主颜色）：定义了字幕文本的**默认填充颜色**。这是字幕在正常显示时使用的颜色，也就是观众看到的大部分字幕文字的颜色。
	这是字幕在正常显示时使用的颜色，也就是观众看到的大部分字幕文字的颜色。
2. **SecondaryColour**（默认次要颜色）的作用主要体现在**卡拉 OK 效果**中。是为**卡拉 OK 效果**预留的颜色，通常是文本被“唱过”之前的颜色。
	 它通常用作**卡拉 OK 效果的后备颜色**或**填充颜色**。
	 在卡拉 OK 字幕中，文本一开始显示为 **SecondaryColour**，然后随着歌词的朗读，被逐渐“填充”成 **PrimaryColour**。这种颜色渐变的效果创造了歌词同步的视觉体验。
	 **SecondaryColour** 只会在你使用特定的卡拉 OK 效果代码（如 `\k`, `\K`, `\kf` 等）时才会被调用。
	 这个值是必填的。如果不需要卡拉OK的话，可以填 **PrimaryColour** 同样的值。或者填完全透明的颜色 `&HFF000000` (通过 Alpha 通道 `FF` 实现完全透明)，这样清楚地表明你没有使用这个字段的意图。
3. **OutlineColour**（默认描边颜色）：字体边缘描边的颜色。    
4. **BackColour**（默认背景色/阴影色）：阴影或边框填充颜色（取决于 BorderStyle）。 
⚠️ 注意：每个颜色都带透明度（Alpha），即可以“半透明”。

ASS 颜色的写法，使用 **Alpha + BGR 顺序**，和一般的 RGB 不一样。  
格式为：
```
&HAA BB GG RR
```
- **&H** 开头：代表十六进制。    
- **AA**：Alpha（透明度），00=完全不透明，FF=完全透明，80=半透明。    
	- 半透明白色：`&H80FFFFFF`
	- 半透明红色：`&H800000FF`
- **BB**：蓝色分量（00–FF）。    
- **GG**：绿色分量（00–FF）。    
- **RR**：红色分量（00–FF）。

| 常见颜色 | 标准 RGB (R,G,B) | ASS 写法 (&HAABBGGRR) |
| ---- | -------------- | ------------------- |
| 白色   | (255,255,255)  | `&H00FFFFFF`        |
| 黑色   | (0,0,0)        | `&H00000000`        |
| 红色   | (255,0,0)      | `&H000000FF`        |
| 绿色   | (0,255,0)      | `&H0000FF00`        |
| 蓝色   | (0,0,255)      | `&H00FF0000`        |
| 黄色   | (255,255,0)    | `&H0000FFFF`        |
| 青色   | (0,255,255)    | `&H00FFFF00`        |
| 品红   | (255,0,255)    | `&H00FF00FF`        |
### 在 Events 覆盖标签中的用法
字幕 `Text` 部分可以局部改颜色：
- **{\c&H...&}** → 设置主颜色/覆盖 **PrimaryColour**（主颜色）
- **{\2c&H...&}** → 设置次颜色 /覆盖 **SecondaryColour**
- **{\3c&H...&}** → 设置描边颜色/覆盖 OutlineColor（描边）  
- **{\4c&H...&}** → 设置阴影颜色/ 覆盖 BackColor
- **{\1a&HAA&}** → 设置主文字透明度（Alpha）    
- **{\2a&HAA&}** → 次颜色透明度    
- **{\3a&HAA&}** → 描边透明度    
- **{\4a&HAA&}** → 阴影透明度
```r
Dialogue: 0,0:00:01.00,0:00:05.00,Default,,0,0,0,,{\c&H0000FF&}蓝色文字 {\3c&H00FF00&}绿色描边
```
- `{\c&H0000FF&}` → 主文字变蓝色    
- `{\3c&H00FF00&}` → 描边变绿色
### 特殊技巧
**透明特效**：
event> dialogue: 用 `\alpha&Hxx&` 可以直接调整体透明度。
```
{\alpha&H80&}半透明文字
```
### ASS 卡拉OK颜色过渡
在 ASS 里，**逐字/逐词的卡拉OK高亮**是通过 **`\k` 标签 + SecondaryColour（次颜色）** 实现的。
- **PrimaryColour** = 原始文字颜色（比如白色）    
- **SecondaryColour** = 高亮颜色（比如黄色）    
- **\kN** = 表示这段文字的高亮持续时间（单位是 1/100 秒，即 0.01s = 10ms）    

显示效果：
1. 默认显示 **PrimaryColour**。    
2. 播放到 `\k` 时间时，这部分文字会从 **PrimaryColour** 渐变到 **SecondaryColour**。    
3. 整句完成后，可以再切回 PrimaryColour（或者保持高亮）。

在 **Events → Dialogue → Text** 里：
```
{\k<时间>}文字
```

|标签|单位|说明|
|---|---|---|
|`\kN`|1/100 秒|最常用，匀速淡入高亮|
|`\K`|1/100 秒|与 `\k` 类似，但立即切换到 SecondaryColour（无渐变）|
|`\kfN`|1/100 秒|匀速填充效果（高亮会像涂色一样填充文字）|
|`\koN`|1/100 秒|字符透明度填充（常用于特殊卡拉OK特效）|

例如, 假设我们有一句歌词：**“我和我的祖国” 样式定义
```ini
Style: Default,Microsoft YaHei,48,
&H00FFFFFF,&H0000FFFF,&H00000000,&H64000000,
-1,0,0,0,100,100,0,0,1,2,2,2,20,20,20,134
```
- PrimaryColour = `&H00FFFFFF` → 白色    
- SecondaryColour = `&H0000FFFF` → 黄色
事件字幕
```ini
Dialogue: 0,0:00:00.00,0:00:05.00,Default,,0,0,0,,
{\k30}我{\k30}和{\k40}我{\k40}的{\k50}祖{\k50}国
```
意思是：
- “我” 高亮 0.30 秒    
- “和” 高亮 0.30 秒    
- “我” 高亮 0.40 秒    
- “的” 高亮 0.40 秒    
- “祖” 高亮 0.50 秒    
- “国” 高亮 0.50 秒 
播放效果：歌词逐字从白色变成黄色，就像卡拉OK的逐字提示。
#### 进阶技巧
1. **多行歌词**  
    如果要做逐行效果，可以用多条 `Dialogue`，每行都加 `\k`。    
2. **双层字幕法**  
    一行 PrimaryColour（底层白字），另一行 SecondaryColour（顶层黄字，带 \k 标签），这样可以做更复杂的卡拉OK特效（比如渐变、发光）。    
3. **配合特效**  
    可以同时用 `\fad` 渐入渐出，或者 `\move` 让歌词移动。
## ASS 动画
ASS 动画类型概览

| 动画类型      | 描述                                                                                                     | 标签示例                                              | 适用场景          |
| --------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------- | ------------- |
| **淡入淡出**  | 字母或整行字幕渐显或渐隐<br>- 参数 `(入,出)` 单位毫秒    <br>- 适合整行歌词淡入淡出                                                  | `\fad(500,500)`                                   | 歌词逐行显示        |
| **缩放/旋转** | 字体从小到大、旋转等<br>- `\fscx` / `\fscy` 分别控制水平/垂直缩放    <br>- `\t(start,end,标签)` 表示从 `start` 到 `end` 时间执行渐变动画 | `\fscx100\fscy100` → `\t(0,500,\fscx150\fscy150)` | 强调某个字或音节      |
| **移动/滚动** | 字幕从一个位置移动到另一个位置<br>参数 (x1,y1,x2,y2) 控制字幕从 (x1,y1) 移动到 (x2,y2)<br>可以结合 \t 做平滑移动：                        | `\move(x1,y1,x2,y2)`                              | 滚动歌词或卡拉 OK 风格 |
| **颜色渐变**  | 字体颜色逐渐改变<br>- `\c&HBBGGRR&` 格式：蓝-绿-红（Hex）    <br>- 结合 `\t` 可以渐变动画                                      | `\c&HFF0000&` 或 <br>`\t(0,500,\c&H00FF00&)`       | 强调特定字         |
| **逐字动画**  | 每个字独立出现、淡入或移动<br>- 每个字显示 0.5 秒 (`50*0.01s`)    <br>- 可和 `\fad`、`\fscx/fscy`、`\c` 结合                    | `\k50`（逐字显示时间）                                    | 歌词跟随节奏逐字显示    |
| **震动/抖动** | 字体微小随机位移                                                                                               | `\pos(x+rand(),y+rand())` 配合 `\t`                 | 增加节奏感或特效感     |
| **路径动画**  | 字母沿路径移动                                                                                                | `\move` + `\t`                                    | 曲线轨迹动画        |
| **旋转/翻转** | 字体旋转、翻转<br>- `\frz`：绕 Z 轴旋转角度    <br>- `\t` 用于渐变旋转动画                                                   | `\frz45` 或 `\t(0,500,\frz360)`                    | 动态歌词效果        |
### 动画技巧
动画标签一定加在 `[Events]` 部分的每行 `Dialogue:` 的最后一对逗号后. `{}` 包裹动画标签

可以单行或多行组合标签

如果是逐字动画，通常每个字都加一段 {} 或 \k 标签

如果有很多行歌词需要同样动画，可以先在 **Style** 定义基础样式，再用 `{}` 在 Events 里做额外动画
    
使用 **Aegisub 可视化编辑**更方便：    
    - 选中一行 → 打开 **Karaoke Generator** → 应用逐字动画 → 自动生成 `{}` 标签        
    - 可以直接预览效果，不用手动写复杂标签
#### **逐字动画**
- 将 LRC 时间戳拆分为每个字 → 转换为 ASS 的 `\k` 标签    
- 用 `\t` 做逐字缩放/颜色渐变，增强动态效果
#### **组合动画**
- 多个动画标签可以用大括号 `{}` 包裹一起写：
```
Dialogue: 0,0:00:12.34,0:00:15.67,Default,,0,0,0,,{\fad(200,200)\move(100,200,300,200)\c&H00FF00&\fscx100\fscy100\t(0,500,\fscx150\fscy150)}Hello, it's me
```
- `{}` 内的标签顺序无严格要求，但建议逻辑清晰：淡入淡出 → 移动 → 颜色 → 缩放 → 渐变动画
- 
- 可以同时用多个标签：
```
{\fad(200,200)\c&HFF0000&\fscx100\fscy100\t(0,500,\fscx150\fscy150)}Hello
```
#### 弹簧缓动
```
{\move(740,1470,540,1470,0,200)
\t(200,230,\pos(555,1470))
\t(230,260,\pos(530,1470))
\t(260,300,\pos(540,1470))}
```
- 先匀速滑入    
- 再左右小幅抖动形成弹簧效果  
#### **退场动画**
`\move()` 回到初始位置，同时可加 `\alpha&HFF&` 淡出
```
{\move(540,1470,740,1470,3650,3820)}
```
原路返回至初始位置
可以配合 \alpha&HFF& 实现淡出

### {\pos(x,y)}
设置字幕在画面上的固定位置。
文字直接显示在 (x, y) 坐标。
坐标单位是 像素(px)，左上角为 (0,0)，水平向右，垂直向下。
```
{\pos(540,1470)}Hello World
```
将文字固定显示在 `(540,1470)`，通常是竖屏视频中心偏下位置。
### {\move(x1,y1,x2,y2,[t1,t2])} 
让字幕在指定时间段内，从 (x1,y1) 移动到 (x2,y2)。
可以产生匀速滑动效果。
如果不指定时间段 t1,t2，默认整个字幕持续时间内执行。
**`move` 会覆盖 `\pos()` 的位置**
- 例如，如果同时有 `\pos(540,1470)`，在 `\move()` 时间段内会无效
```
{\move(x1,y1,x2,y2,t1,t2)}
```

|参数|说明|
|---|---|
|x1|起点水平位置|
|y1|起点垂直位置|
|x2|终点水平位置|
|y2|终点垂直位置|
|t1|开始时间（ms，可选）|
|t2|结束时间（ms，可选）|
例子
```
{\move(740,1470,540,1470,0,200)}Hello
```
- 从 `(740,1470)` 移动到 `(540,1470)`    
- 0–200ms 内完成    
- 形成从右滑入的效果
### {\t()}
\t() 是一个非常强大的过渡动画（transition）标签，用于让字幕样式的某些属性在一段时间内平滑变化，例如：颜色渐变、移动、缩放、透明度变化等。
```
\t(<t1>,<t2>,<accel>,<style_changes>)
```
或
```
\t(<style_changes>)
```
说明

|参数|含义|示例|
|---|---|---|
|`<t1>`|动画开始时间（毫秒）|`\t(0,500,...)` 表示从字幕出现的0ms开始|
|`<t2>`|动画结束时间（毫秒）|`\t(0,1000,...)` 表示在1000ms内完成动画|
|`<accel>`|动画加速度（可选）|默认为1（线性），>1加速，<1减速|
|`<style_changes>`|要变化的样式标签|可以是 `\alpha`、`\fs`、`\c`、`\bord` 等|
常见动画

|作用|示例|
|---|---|
|渐变颜色|`\t(\c&HFF0000&)`|
|改变透明度|`\t(\alpha&H00&)`|
|改变字体大小|`\t(\fs60)`|
|改变描边或阴影|`\t(\bord4\shad2)`|
|多阶段动画|多个 `\t()` 连用|
字体颜色渐变
```
{\t(0,1000,\c&H0000FF&)}Hello!
```
意思是：  
从出现的0ms到1000ms内，文字颜色**渐变为蓝色（`#FF0000` → `#0000FF`）。

字体放大动画
```ass
{\fs20\t(0,500,\fs60)}BOOM!
```
意思是：  
文字从 **20号字** 在0到500毫秒内**放大到60号字**。

淡入淡出效果（透明度变化）
```
{\alpha&HFF&\t(0,1000,\alpha&H00&)}Hello!
```
意思是：  
文字从**完全透明**逐渐变成**完全不透明**（实现淡入效果）。

同时改变多个属性
```
{\t(0,1000,\fs40\c&H00FF00&\bord6)}Hey!
```
意思是：  
在1秒内同时改变：
- 字号 → 40    
- 颜色 → 绿色    
- 描边 → 6px
- 
带加速度的动画
```
{\t(0,1000,2,\fs50)}Zoom!
```
意思是：  
动画持续1秒，但变化速度**越来越快**（加速度为2）。

高级技巧
你可以**嵌套多个 `\t()`** 实现分段动画：
```
{\fs20\t(0,500,\fs40)\t(500,1000,\fs30)}Bounce!
```
表示：
- 前500ms 字体从20 → 40    
- 接着500–1000ms 再缩回30

### 最常用、最实用的 **ASS 字幕 `\t()` 动画效果模板 10 组**
每个模板都能直接在 `.ass` 文件里使用。  
我会告诉你动画的**视觉效果**、**对应代码**和**可调参数**。

---
## 🎬 【1】淡入效果（Fade In）

**视觉效果**：文字从透明慢慢显现。

`{\alpha&HFF&\t(0,800,\alpha&H00&)}Hello!`

- 从完全透明 → 完全不透明
    
- 可调参数：`800` 表示动画时长（毫秒）
    

---

## 🎬 【2】淡出效果（Fade Out）

**视觉效果**：文字逐渐消失。

`{\alpha&H00&\t(0,800,\alpha&HFF&)}Goodbye!`

- 从不透明 → 透明
    
- 可用于句尾或过场文字
    

---

## 🎬 【3】颜色渐变（Color Transition）

**视觉效果**：文字颜色平滑过渡。

`{\c&H0000FF&\t(0,1000,\c&HFF0000&)}Color Shift`

- 蓝 → 红
    
- 可换颜色码：`&HBBGGRR&` 格式
    
- 可与描边颜色 `\3c` 一起用
    

---

## 🎬 【4】放大出现（Zoom In）

**视觉效果**：从小到大放大出现。

`{\fs20\t(0,600,\fs60)}BOOM!`

- 从字号 20 → 60
    
- 适合标题或强调字
    

---

## 🎬 【5】弹性缩放（Pop/Bounce）

**视觉效果**：先放大再缩小，像弹出一样。

`{\fs20\t(0,400,\fs60)\t(400,700,\fs40)}Pop!`

- 0–400ms 放大
    
- 400–700ms 缩回
    
- 常用于强调、惊讶、拟声词
    

---

## 🎬 【6】颜色闪烁（Color Blink）

**视觉效果**：颜色快速闪烁一次。

`{\t(0,200,\c&H00FF00&)\t(200,400,\c&HFFFFFF&)}FLASH!`

- 绿色闪白色
    
- 可重复定义多个 `\t()` 实现多次闪烁
    

---

## 🎬 【7】描边渐变（Outline Grow）

**视觉效果**：文字描边从细到粗。

`{\bord0\t(0,600,\bord6)}Outline!`

- 从无边到粗边
    
- 配合 `\shad` 可加阴影变化
    

---

## 🎬 【8】发光扩散（Glow Effect）

**视觉效果**：文字逐渐发光（描边和阴影同时增加）。

`{\bord2\shad0\t(0,700,\bord8\shad4\alpha&H80&)}Glow~`

- 从普通到强光再淡化
    
- 适合魔法、梦境、闪烁类场景
    

---

## 🎬 【9】上下浮动（Float Up / Down）

**视觉效果**：文字轻轻漂浮移动。

`{\move(320,400,320,370,0,1000)\t(0,1000,\alpha&H40&)}Float~`

- Y坐标从 400 → 370
    
- 同时轻微淡出
    
- 可组合循环制造漂浮字幕感
    

---

## 🎬 【10】呼吸闪光（Breathing Text）

**视觉效果**：文字亮度周期性变化（像在“呼吸”）。

`{\1c&HFFFFFF&\3c&H000000&\t(0,400,\1c&HAAAAAA&)\t(400,800,\1c&HFFFFFF&)}Breathe`

- 亮 → 暗 → 亮
    
- 可重复定义在多帧字幕中形成循环
    

---

## 💡 进阶建议

想做更炫的动效，可以**组合多个标签**：

`{\fs20\bord2\c&H00FFFF&\t(0,600,\fs40\bord6\c&HFF00FF&\alpha&H20&)}Magic Word!`

👉 同时放大 + 改颜色 + 加描边 + 半透明

#### 例子
想让放大后有“弹跳”感，可以加一个回弹段落：
文字一开始淡入出现 → 在前0.5秒内从正常大小逐渐放大1.5倍 -> 回落到1.2倍 → 保持显示 → 最后淡出消失。
```s
{\fad(200,200)\c&HFF0000&\fscx100\fscy100\t(0,500,\fscx150\fscy150)\t(500,800,\fscx120\fscy120)}Sing with me!
```
